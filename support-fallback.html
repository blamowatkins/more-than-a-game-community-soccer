L6 · Support and Fallback Record

Project: More Than a Game: How Community Soccer Brings People Together

MDN references checked: November 14, 2026.

This record explains the CSS features used, their layout and layering effects, and their fallbacks. The observations below summarize the browser checks; the complete test record is in test-record.html.

Features, effects, and fallbacks

Anchored series badge
On wide screens, the badge uses absolute positioning inside the relatively positioned feature header. The header's padding box is its containing block, and its spacing reserves room for the title. On narrow screens, the badge returns to normal flow. Reference: MDN position .
Bounded sticky navigation
Sticky positioning is enabled only when the viewport is at least 52rem wide and 38rem tall. The navigation sticks 1rem from the block start. Its travel is bounded by main.story-layout; the viewport supplies the scrolling reference. Narrow or short viewports use static positioning. Reference: MDN position .
Controlled quotation overlap
On wide screens, a negative block-start margin overlaps the quotation into space reserved below the figure. The quotation remains in flow. Relative positioning and a non-auto z-index create its local stacking context. The overlap is removed on narrow screens. References: MDN stacking contexts and MDN z-index .
Clipped feature artwork
A polygon clips only the feature image. The image's border box supplies the clipping reference box. A non-none clip-path creates a stacking context without changing the image's layout footprint. The caption stays outside the clipping. Without clipping, the full rectangular image remains visible. Reference: MDN clip-path .
Circular editorial wrapping
On wide screens, the soccer-ball image floats when the browser supports the circle shape and logical float used by the stylesheet. Its border box defines the wrapping circle, and a 1rem shape margin separates the text from the image. The section uses flow-root to contain the float. Without the enhancement, the image remains in normal flow. Disabling only shape-outside leaves rectangular float wrapping. References: MDN shape-outside , MDN shape-margin , and MDN float .
Rounded presentation
border-radius rounds the feature frame and the soccer-ball image. It does not change their basic layout footprints or create stacking contexts. The figure keeps overflow visible so captions and focus outlines are not clipped. Without rounding, the content remains complete. Reference: MDN border-radius .
Feature queries
The stylesheet checks the polygon, circle, and logical-float declarations it uses. A successful feature query does not prove that every part of the enhanced layout works correctly; browser testing is also required. Reference: MDN @supports .

Documented layer scale

  • --layer-base: 0 — normal content and base painting level.
  • --layer-raised: 10 — the wide-screen quotation.
  • --layer-sticky: 20 — navigation when sticky positioning is enabled.
  • --layer-overlay: 30 — reserved; no overlay currently uses it.

These levels are local to their stacking contexts. The clipped image, wide-screen quotation, and sticky navigation can each create a context. The header and badge retain automatic stack levels. DevTools showed position: static and z-index: auto for img.shape-portrait; its float does not require relative positioning.

Interaction protection

Both illustrations use pointer-events: none. Captions, quotation attribution, and navigation links remain outside clipped image content. Pointer and keyboard checks confirmed that the links remained usable and focus stayed visible.

CSS validation note

The W3C CSS Validator reported unsupported-property errors for shape-outside and shape-margin, plus CSS-variable warnings. Chrome applied the shape values during browser inspection. See the validation evidence and detailed result in the test record.
